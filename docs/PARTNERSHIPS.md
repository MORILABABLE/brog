## 0. 結論（先に5つ）

1. **外からの信号はほぼゼロ。** 28日で Referral 1セッション。サイト内の手は打ち尽くしつつあり、
   **4〜10位に溜まっている表示（FUNNEL 4節）を上に押すのは、残りは外部の評価しかない**
2. **提携の形は、API規約で絞られる。** 「データを単体の商品として出すこと」と
   「配信情報を第三者に渡すのが主目的の形」が禁止（3-1）。**ウィジェット配布・データの提供はアウト**。
   **記事・プレスリリースに数字を書くのは、帰属表示つきで明示的に認められている**
3. **その形にいちばん合う手は「観測データのデジタルPR」。** 月次の一覧はどこでも出しているが、
   **「配信終了の傾向」を数字で出しているところは見つからなかった**（2-3）。
   ここはこのサイトにしか出せない
4. **同業の個人サイトは、推定で前月比 −7〜−9%。** 絶対数（推定8〜16万訪問/月）は6か月では
   追いつかない。**「平均を上回る」は伸び率と参照ドメイン数で測る**（2節・7節）
5. **リンクが付く手は 2026-10-01 以降に出す。** 7-7 の判定（FUNNEL 7-7-3）と
   9/27 の読み（FUNNEL 10節）が済むまでは、準備（規約確認・出典ページ・連絡先リスト）だけにする

## 3. 提携の形を絞る制約（4つ）

### 3-1. Streaming Availability API の規約 — **いちばん強い制約**

> 🔺 **訂正（2026-09-16 夜）。** 初版は GitHub の
> [TERMS.md](https://github.com/movieofthenight/streaming-availability-api/blob/main/TERMS.md) を引いていたが、
> **あれは旧版だった。** 現行は
> [developers.movieofthenight.com/terms-and-conditions](https://developers.movieofthenight.com/terms-and-conditions)
> （JavaScript で描く画面なので WebFetch では本文が取れない。`assets/terms-and-conditions-*.js` を直接読んだ）。
> 旧版の「**to other businesses or platforms in any way**」は**無くなり、禁止の範囲が狭くなった。**

現行の原文（3節・4節）:

> The API User shall not resell, sublicense, redistribute, publish, or otherwise make the data available
> **as a standalone data product, API, database, or service**, or in any manner
> **whose primary purpose is to provide streaming availability data to third parties.**

> If the API User uses the data or images in **written content such as articles, blog posts,
> or research publications**, attribution must also be included.
> In all cases, the attribution must include a link to: https://www.movieofthenight.com/about/api

| 提携の形 | 判断 |
|---|---|
| 他サイトに**埋め込むウィジェット／ブログパーツ**（終了カウントダウン等） | ❌ 配信情報を第三者のサイトに渡すのが主目的 |
| メディアや動画制作者に**一覧データ（表・CSV）を渡す** | ❌ 単体のデータ提供 |
| **ニュースアプリ・キュレーションへの記事配信**（SmartNews・グノシー等） | △ 記事なら読める余地はあるが、**一覧記事は「配信情報を渡すのが主目的」に近い**。どのみち 3-3 で使えない |
| 向こうが**こちらの公開ページを出典としてリンク**する | ✅ こちらが渡しているのではない |
| **集計値**（「9月末の終了はN本」）をプレスリリース・寄稿に載せる | ✅ **written content として明示的に認められている**（帰属表示とリンクが条件）。**P-1 は念のための確認**に格下げ |

> 🔴 **作品ページの話だが、ここで見つけたので書いておく。** 現行 5節は
> ポスター等を **Third-Party Content** とし、「**API提供元は利用許諾を出さないし、出せる立場にない**」
> 「適法かどうかの責任は API利用者が負う」と明記している。
> 2026-08-25 に得た「再ホストしてよい」（[HANDOVER](./HANDOVER.md)）は**提供元としての技術的な可否**であって、
> **権利者の許諾ではない**と読むべき。運営方針の「許諾を受けた」という書き方と合わせて、**別途見直しが要る。**
> 通知があれば該当画像を速やかに消す義務もある（5節）。

> ★ 現状の帰属表示は `site/src/config.ts:65` と各記事の frontmatter にあり、条項を満たしている。
> **外に出す文書（プレスリリース・寄稿）にも同じ帰属を必ず入れる。**

> ★ **U-NEXT の数字は外に出す集計に入れない。** 台帳は「公開物の素材ではない」
> （[GROWTH 2-3](./GROWTH.md)）。記事の断面は許しているが、月をまたいだ集計を外部に配ると
> 台帳を素材にしたのと同じになる。入れるならそこに日付と理由を書いてから。

### 3-2. Google のスパムポリシー

[スパムに関するポリシー](https://developers.google.com/search/docs/essentials/spam-policies?hl=ja)が
リンクスパムとして挙げているもの（抜粋）:

- **過剰な相互リンク**（「リンクする代わりにリンクしてもらう」）
- **ゲスト投稿・プレスリリース内の作為的なアンカーテキスト**
- さまざまなサイトに配布される**ウィジェットに埋め込まれたリンク**
- ランキングクレジットをブロックしない**有料のテキストリンク**

加えて**サイトの評判の不正利用**（他サイトの評価に乗るための第三者コンテンツ）。
ただし**プレスリリース配信サイト自体は違反にならない例**として挙がっている。

→ **プレスリリースは出してよい。アンカーを作品名＋「配信終了」で埋めない。**
リンクは「見放題レーダー」か URL そのものにする。

### 3-3. 運営者が「見放題レーダー編集部」（個人・名前なし）

| 窓口 | 個人・匿名で使えるか |
|---|---|
| SmartNews への記事配信 | ❌ **法人運営が原則・個人ブログ不可**。SmartFormat は**新規受付停止中** |
| PR TIMES スタートアップチャレンジ（無料10件） | ❌ **法人のみ**。個人事業主は対象外 |
| PR TIMES 従量課金 | ✅ **1件3万円（税別）** |
| ValuePress フリープラン | ✅ **0円・1回・約20媒体**（1日1回のダイジェスト配信） |
| Yahoo!ニュース エキスパート | ❌ クリエイター/地域カテゴリは **2026-03-31 で終了**。オーサーは実績で審査 |
| 記者への直接連絡 | ✅ ただし**名乗れる連絡担当が要る**（匿名の編集部名だけだと返信率が落ちる。未検証） |

> ★ **運営者名を出すかどうかは運用者の判断。** 出さない場合は、プレスリリースと記者連絡の
> 確度が下がる前提で計画する。

### 3-4. ブランド（[運営方針](./・当サイトの運営について.txt)）

「許諾を受けたデータ」「権利を侵害しない」「観測できた数であって起きた数ではない」。
**頼んでリンクを貼ってもらう形・数で押す形は、この3つと相性が悪い。**
**向こうが引用したくなる事実を置いて、引用のしかたを明示しておく**のが合う。

- アンカーは作品名かサイト名。「配信終了 一覧」のような語で揃えない

## 7. 測り方と、外れたと分かる形

「同業の平均を上回る」を、測れる形に直すとこうなる。

| 見るもの | どこで | いま | 2027-03 に見たい形 |
|---|---|---|---|
| **検索ユーザーの前月比** | `npm run analytics` | 横ばい（1節） | **プラスが続く**（同業推定 −7〜−9%/月を上回る） |
| **参照ドメイン数** | GSC「リンク」 | 未確認（ほぼ0と推定） | **媒体2件以上を含む10ドメイン以上** |
| Referral セッション | GA4 経路 | 1 / 28日 | 出典リンク経由が毎月出ている |
| **4〜10位にいる作品ページの割合** | analytics「順位帯 × ページの種類」 | 表示の91%が4〜10位（FUNNEL 4節） | **1〜3位への移動が出る**（外部の評価が効いたかの本命） |
| AI Assistant セッション | GA4 経路 | 13 / 28日 | 付記参照 |

**外れたと分かる形:**

- P-3 を3か月（10〜12月）続けて**出典リンクが1本も付かない** → 月次の一言は媒体に届かない。P-4 一本に絞る
- P-4 を出して**30日で参照ドメインが増えない** → 「傾向データは引用される」という前提が違う。PR をやめ、サイト内の施策に戻す
- 参照ドメインは増えたのに**4〜10位帯が動かない** → リンクの質か、ページ側の問題。リンク獲得を続ける理由が無くなる
