# 記事テンプレート: シリーズ（保存版）

このファイルを編集すれば、全てのシリーズ記事の構成が変わる。コードを触る必要はない。

- そのまま使う文言 → `fixed-phrases.md`（`series-` で始まるキー）
- **軸とタイトルの決まり → `naming.md`**（全記事タイプ共通）
- 月次のまとめ記事 → `leaving.md` / `ended.md` / `arrivals.md` / `arrivals-service.md`
- そのつど出す特報 → `special.md`

## この記事だけが月を名乗らない

**他のすべての記事は「その月に何が起きたか」を書く。この記事は「いま全作がどうなっているか」を書く。**

| | 月次記事・特報 | シリーズ（この記事） |
| --- | --- | --- |
| URL | `2026-09-leaving-netflix` | **`conan-movies`（月が入らない）** |
| タイトル先頭 | 【2026年9月】 | **【保存版】** |
| 素材の範囲 | その月に観測したぶん | **全期間。シリーズの全作** |
| 次の月 | 新しい記事を書く | **同じ記事を書き直す** |

だから**本文でも月を名乗らない。**

- ×「9月にNetflixで終了する『名探偵コナン』は……」
- ○「『名探偵コナン』劇場版シリーズのうち、27本の終了日が判明しています」

書き直すたびに終了日は入れ替わる。**その時点の日付は表と「（○月○日時点）」で示し、
記事全体を特定の月のものにしない。**

## ★ この記事タイプでいちばん大事な決まり

**終了日が過ぎても、説得力が落ちない記事にする。**

この記事は、対象作品が全部終わったあと「終了予定」→「終了しました」に書き換えて
**同じURLで使い続ける**。だから、**期限が来たら価値を失う部分を記事の中心に置かない。**

| 期限が来ると価値を失う | 期限と関係なく残る |
| --- | --- |
| 「あと◯日です」「今のうちに」 | **そのシリーズが何なのか** |
| 「区切りは◯月◯日で共通です」 | **どこまで作られ、どう受け止められてきたか** |
| 終了日を何度も言い直す | **どの作品がどのサービスにあるか** |

終了日は**リードと表で1回ずつ言えば足りる**。地の文で繰り返さない。
空いた行数は、**作品そのものの説明**に使う。

> **量より質。** 分量はすでに表で足りている。
> 文章の役目は「表に出ていないこと」を足すことだけ。

## 軸とタイトル

**この記事の軸は「主題1つ」。** シリーズ名・作品群など、人が指定した主題を扱う。
主題の記事なので**サービスを横断してよい**し、1社の話ならその社名をタイトルに出してよい。

動詞句は**素材から決まる**（人が選ぶフラグは無い）。

| 素材の状態 | 動詞句 | 記事の性格 |
| --- | --- | --- |
| 1本でもまだ観られる | `見放題配信が終了予定の` | いつまで観られるか。締切がある |
| **終了予定は無いが、見放題に復帰した作品がある** | `見放題配信が再開した` | **また観られるようになった。締切は無い** |
| **全部終わっている** | `見放題配信が終了した` | いつまで観られたか。次の一手だけを渡す |

★ **順番に意味がある。** 上から見て最初に当てはまるものを使う。
  終了予定と復帰が混ざる記事では、締切のあるほうを名乗る。

> 【保存版】「名探偵コナン」劇場版シリーズの見放題配信が終了予定の作品61本｜ベイカー街の亡霊と純黒の悪夢
> 【保存版】「007」シリーズの見放題配信が終了予定の作品5本【9月12日更新】｜スカイフォールも終了

★ **タイトルに日付を書かない。** 年月（2026年9月）も、終了日（8月31日まで）も。
  品質ゲートが止める。書き直すたびに入れ替わる値なので、
  **タイトルに入れると次の書き直しまで嘘になる。** 終了日は本文の表に出す。
  更新版の 【9月12日更新】 だけは例外（更新の印なので）。

## 何を答える記事なのか

読者が打っている語はこの形（サジェスト実測。docs/KEYWORDS.md 3-3）。

> コナン 映画 配信 いつまで ／ コナン 映画 配信終了 ／ コナン 映画 配信 netflix

**答えるのは「そのシリーズが、どこで、いつまで観られるのか」。**
そのうえで、**「なぜこのシリーズを追う価値があるのか」**を素材の事実で示す。

- あらすじの紹介記事にしない。読者は作品を知っている
- 「シリーズの魅力」「おすすめの順番」を**素材なしで**書かない
- リサーチ（`npm run research`）で取れた事実は積極的に使う。
  **累計動員・受賞・記録・作り手の交代・人気投票の順位**は、どれも期限と無関係に残る

## 書き直し（状態が変わったとき）

> 全記事タイプ共通の決まりは `naming.md`「前の版の本文が渡された回」にある。
> ここはそれを**この記事タイプに落としたもの**で、
> **月次記事の「版（初回と更新版）」に当たる節**でもある。

**この記事は同じURLを何度も書き直す。書き直しは「差し替え」であって「書き下ろし」ではない。**

> **あらすじも、一度調べた作品の特徴も、書き直す必要はない。**
> **「見放題が終了した状態」で読んでも違和感が出ないところだけを直して、記事を遷移させる。**

これが書き直しの判断基準そのもの。段落ごとに「この文は、終了したあとに読んでも
おかしくないか」だけを見る。おかしくなければ**触らない**。

    1997年の第1作『時計じかけの摩天楼』から2024年の第27作『100万ドルの五稜星』まで、
    劇場版は27作すべてが対象です。                          ← 終了後も真。触らない

    見逃さないようにチェックしましょう！                     ← 終了後は嘘。直す

`npm run write -- --refresh` が拾うのは「終了予定だった作品が終了済みになった」ように
**事実のほうが変わった記事**で、変わるのはごく一部でしかない。
プロンプトに**前の版の本文**が付いている回は、それを土台にして下の欄だけを差し替える。

| 差し替える | そのまま残す |
| --- | --- |
| タイトルの動詞句（上の表） | タイトル先頭の 【保存版】 |
| タイトルの本数と `【{月}月{日}日更新】` | 見どころ（`｜` の後ろ。事実として誤りでなければ） |
| リードの1文目（固定文言が入れ替わる） | リード2段落目のシリーズの説明 |
| 節の見出し（`終了する◯本` → `終了した◯本`） | 節の解説（調べた事実で書いた段落） |
| 表の「状態」の列 | **表の行そのもの**（前の版に載っていた作品を落とさない） |
| 行動を促す言い回し（下の「書いてはいけないこと」） | 「他のサービスで探す」「まとめ」 |

★ **解説の段落を書き直さない。** リサーチ（`npm run research`）で調べた事実で書いてある。
  同じ材料からもう一度書くと**別の文章になって、内容が静かに痩せる。**
  事実が変わっていない段落に手を入れる理由は無い。

★ **生成のあとで手を入れた一文を消さない。** 他社との相互参照のように、
  記事を書いたあとで足された文がある（docs/EDITING.md「他社の話を1文だけ足すとき」）。
  事実として誤りになっていなければ残す。

★ **全作品が終了済みになった回だけは、行動を促す言い回しを1つ残らず消す。**
  「お見逃しなく」「今のうちに」「観ておきましょう」「配信中です」。
  ここは残してはいけない（品質ゲートが止める）。

## 構成

### 1. リード（2段落）

**1文目は `fixed-phrases.md` の文言をそのまま使う**（素材の状態で決まる）。
主題・サービス名・基準日・本数だけが差し替わる。文型は変えない。

**★ リードの締めの固定文言は無い。** 月次記事と違い、行動の促しは1文目の末尾に入っている。
2段落目を「観ておきましょう」で締め直さないこと。**同じことを2回言うことになる。**

2段落目は、**そのシリーズがどれくらいのものなのかを1〜3文で**。

- 何作あるか、いつからいつまでか
- リサーチで取れた記録（累計動員数・興行収入の到達点など）が1つあれば十分
- 作品名・シリーズ名は「」または『』で囲む

### 2. サービスごとの節

**サービス1社につき1節。** 見出し → 表 → 解説の順にする。導入文を挟まない。

```
## （サービス名）で見放題配信が終了する◯本

| 終了日 | 作品 | 状態 | 評価 | サービス |
| --- | --- | --- | --- | --- |
| …… | …… | …… | …… | …… |

（ここから解説）
```

- 表の列は **終了日・作品・状態・評価・サービス** の5列で固定する
  （1サービスの記事でもサービス列を省かない。サイトが行のサービス名を読んでリンクを付ける）
- **状態列を省かない。** 終了予定・終了済み・見放題に復帰が混ざる記事では、
  これが無いと読者は1行ずつの可否を判断できない（品質ゲートが止める）

#### ★ 「見放題に復帰」の行

一度見放題から外れたあと、**また見放題で観られるようになった作品**。
素材の「状態」がこの値になっている行がそれで、`series.ts` が観測から自動で判定する。

| | 書き方 |
| --- | --- |
| 状態の欄 | `見放題に復帰` |
| **終了日の欄** | **`—`。次の終了日は分かっていない** |
| 地の文 | どこで終わってどこへ戻ったかを1文。**いつまで観られるかは書かない** |

- **終了済みの行とまとめない。** 別の事実で、日付の意味も違う
  （終了済みの行の日付は「終わった日」、復帰の行に日付は無い）
- 「当面は観られます」「◯月までは大丈夫」と書かない。**素材にその根拠が無い**
- 復帰の理由（契約・権利）を推測しない

#### ★ 同じ作品を2回表に出さない

同じ映画が、サービスごとに違う題で入っていることがある。

    Netflix   名探偵コナン ベイカー街の亡霊
    U-NEXT    劇場版 名探偵コナン ベイカー街（ストリート）の亡霊

素材には**サービスごとに1件ずつ**入っている（終了日が別々に決まるため）。
だが**表に2行出すと、読者には別の作品に見える。**
素材に `★同じ作品が … にもあります` と書かれている行は、**表に1回だけ出せばよい。**

**やり方は「2社目の節を、そちらにしか無い作品だけの表にする」。**

    ## Netflixで見放題配信が終了する29本
    （29行の表。サービス列は Netflix）

    ## U-NEXTで見放題配信が終了する32本
    （U-NEXTにしか無い3行だけの表。サービス列は U-NEXT）
    残る29本はNetflixと同じ作品です — と1文で書けば、読者には十分わかる

##### 本数はまとめたあとの数で名乗る

同じ作品を1行にまとめると、**素材の件数と表の行数がずれる**。
タイトルとリードで名乗るのは**まとめたあと（作品の数）**のほう。

    素材 6件（実写5作＋『最後の騎士王』が Amazon Prime Video と Disney+ の2社ぶん）
    表   5行
    → 「作品5本」と名乗る

★ **ズレの理由を本文に書かない。** 「件数が6本になっているのは、『最後の騎士王』だけが
  2つのサービスで扱われていて…」のような断り書きは、**読者には冗長で記事の流れを切る**。
  管理者にとっては納得のいく説明でも、読者が求めている情報ではない
  （2026-08-31 の添削）。数はリードの固定文言と揃うよう自動で出るので、
  **書き手はただその数を使えばよい。**

★ **節の見出しの本数は別**。あちらは「そのサービスで終了する総数」で、
  読者が自分の契約先で何本終わるかを見る数字（下の項）。

- **サービス列には1社だけを書く。** `Netflix / U-NEXT` と併記しない。
  サイトは行のサービス名を読んで作品ページへの送り先を決めているので、
  併記するとその手がかりが消える
- 見出しの本数は**そのサービスで終了する総数**（上の例なら32本）。
  表の行数と違ってよい。読者が知りたいのは「自分の契約先で何本終わるか」
- **終了日が違う場合はまとめない。** 別の行にして、それぞれの日付を出す

### 3. 解説（各節の表のあと）

**表に出ていないことだけを書く。** 表を日本語で読み上げ直さない。

書いてよいこと（素材とリサーチにある事実だけ）:

- そのシリーズが何作あり、どこまで揃っているか
- **人気や規模の裏づけ** — 累計動員数、興行収入の到達点、人気投票の順位、記録
- 作り手の交代、シリーズの転機になった作品
- そのサービスにしか無い作品が何か

書いてはいけないこと:

- **数字の羅列。** 「第◯作は◯億円、第◯作は◯億円……」を並べない。
  規模の変化は**始点と到達点、転機の1つ**を示せば伝わる
- 配信の裏側（契約・権利）の推測
- 表の並べ方の説明（「◯本ずつ並べています」「こちらの並びの特徴は」）

### 4. 他のサービスで探す

冒頭の固定文言をそのまま置き、検索リンクを並べる。

★ **この節を「横断だから」と削らない。** 全作品が終了済みの記事では、
  ここが記事の中心になる（読者に渡せる次の一手がこれしかない）。

### 5. まとめ

**2〜4文。** どこで何本が対象かを一度だけ言い直し、次の一手（検索リンク）に送る。
シリーズの感想・視聴の勧め方を新しく書き足さない。

### 6. 末尾

出典表記を固定文言のままそのまま置く。素材の出どころが混ざる記事では**全部**置く。

## 書いてはいけないこと

- **終了済みの作品に「お見逃しなく」「今のうちに」「観ておきましょう」「配信中です」**
  混在する記事では、行ごとに書き分ける。まとめて煽らない
- **まだ終わっていない作品に「終了しました」**
- **U-NEXT の作品に「観られなくなります」**
  ポイント（レンタル・購入）での取り扱いが続く作品がある。
  U-NEXT が入る記事では `series-unext-note` の固定文言をそのまま置く
- **評価スコアを地の文に書く。** 表にだけ載せる
- **素材に無い人名・あらすじ・公開順・興行成績**
- **記事の作りや更新方針の解説。** 「この記事は毎月更新しています」は固定文言の中だけ
