# 文章の決まり（全記事タイプ共通）

**構成は記事タイプごとのテンプレートにある。** ここにあるのは、
どの記事でも同じように守る書き方の決まり。

> ★ タイトルの決まりが `naming.md` に1枚だけあるのと同じ理由で、ここも1枚にしてある。
>   4つのテンプレートに書き写すと、必ずどれかが古くなる。

---

## 1. 記事の作りを読者に説明しない

**読者は「何が観られるか」を知りたい。記事がどう組み立てられているかは要らない。**

節のまとめ方（同じ日・同じシリーズ・同じ制作会社）は**書き手の都合**であって、
読者に伝える情報ではない。まとめ方をそのまま文章にすると、
作品の話が消えて「並び方の解説」になってしまう。

結びは、**読者が次にできること**で終える。

| ✕ 記事の作りの説明 | ○ 読者に向けた自然な言い方 |
| --- | --- |
| シーズン1〜2と合わせて、同じ日に続けて観られる並びです。 | シーズン1〜2と合わせて視聴してみましょう！ |
| 3期分が同じ日にそろうので、1期から順に追うにも続きから観るにも起点になります。 | 1期から順に、3期分をまとめて楽しめます。 |
| 日をおいて1本ずつ増えていく並びになっています。 | 気になる作品の配信開始日を控えておきましょう。 |
| 月末に向けて話題作が続く並びです。 | 月末にかけて話題作が続きます。 |

**使わない言い回し**（品質ゲートが見ている）

    〜という並びです／並びになっています
    〜する形です／形になっています
    〜の起点になります
    〜という構成です

> ★ 「9月1日に11作がまとめて配信開始予定です」は**事実**なので書いてよい。
>   禁じているのは、事実のあとに付ける**「並びです」「形です」という記事側の説明**。

## 2. 配信の裏側を推測しない

**ライセンス・権利・契約の事情は、素材のどこにも無い。**
同じ制作会社の作品が同じ日に並ぶ理由を、こちらで推し量って書かない。

| ✕ | ○ |
| --- | --- |
| まとめてライセンスされたものが同時に配信開始となったと考えられます。 | （書かない。かわりに作品そのものを1〜2文で説明する） |
| 契約が切れたため一斉に終了するとみられます。 | 5作とも9月1日に見放題配信が終了します。 |

**「同じ制作会社の作品です」までは事実なので書いてよい**（素材に制作会社がある場合）。
そこから先の**なぜ**に踏み込まない。

> ★ 外れても読者には確かめようがなく、当たっていても観るかどうかの判断は変わらない。
>   **書く理由が無い一方で、外したときの損は記事全体の信用に及ぶ。**

その分の行数は、作品の説明に使う。あらすじ・監督・出演者・制作会社は素材にある。

## 3. 作品の魅力は「事実」で書く

**あらすじの言い換えで終わらせない。** 読者が知りたいのは
「どんな話か」だけでなく「**なぜその作品が好かれているのか**」。

素材に `リサーチ` の行がある作品は、そこにある事実を根拠に**1文足す。**
作風・評判・広がり方は感想ではなく事実なので、調べたうえで書けば推測にならない。

| ✕ あらすじだけ | ○ 魅力まで届く |
| --- | --- |
| 高校生のなでしこが富士山を見に自転車で本栖湖へ向かう話です。 | ソロと大人数のキャンプを対等に描くのが持ち味で、実在のキャンプ場を作者が下見して描いた風景と、道具や野外調理の手つきがそのまま画面に出ます。 |
| 白熊がカフェを始める日常アニメです。 | 動物たちの脱力した掛け合いと言葉遊びが続く1本で、原作は◯◯万部を超えています。 |

**使える事実の例**

- 作風・語り口（何をどう描く作品か）
- 累計発行部数・興行収入・受賞歴など、**数字と固有名詞で言えるもの**
- シリーズの広がり（何期まで作られたか、劇場版があるか、実写化されたか）
- 舞台になった土地（聖地巡礼で知られる、など）

**やってはいけないこと**

- **リサーチの文章をそのまま写す。** 出典は CC BY-SA で、写せば同じ条件での
  再配布義務が生じる。**事実だけを読み取って、こちらの言葉で書く**
- リサーチが**別作品**（小説版・ドラマ版・同名の別作品）のときに使う。
  素材の `出典:` を見て、対象作品の項目かどうかを必ず確かめる
- リサーチが無い作品を、他の作品の情報や自分の記憶で埋める。
  **無い作品は素材の範囲で書く**（1〜2文で終わってよい）
- 数字を丸めたり盛ったりする。**書けるのは素材にある数字だけ**

> 下調べは `npm run research` が日本語版 Wikipedia の「概要」「作風」「評価」節から集める。
> 取れなかった作品には `リサーチ` の行が無い。

## 4. 事実と、事実でないものを混ぜない

- 素材に無い日付・数字・人名を書かない（各テンプレートの「絶対に守ること」）
- 「〜と考えられます」「〜とみられます」で**推測を事実らしく見せない。**
  推測が必要な場面なら、そもそも書かない
