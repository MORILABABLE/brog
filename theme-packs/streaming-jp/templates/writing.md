# 文章の決まり（全記事タイプ共通）

**構成は記事タイプごとのテンプレートにある。** ここにあるのは、
どの記事でも同じように守る書き方の決まり。

> ★ タイトルの決まりが `naming.md` に1枚だけあるのと同じ理由で、ここも1枚にしてある。
>   4つのテンプレートに書き写すと、必ずどれかが古くなる。

---

## 1. 記事の作りを読者に説明しない

**読者は「何が観られるか」を知りたい。記事がどう組み立てられているかは要らない。**

節のまとめ方（同じ日・同じシリーズ・同じ制作会社）は**書き手の都合**であって、
読者に伝える情報ではない。まとめ方をそのまま文章にすると、
作品の話が消えて「並び方の解説」になってしまう。

結びは、**読者が次にできること**で終える。

| ✕ 記事の作りの説明 | ○ 読者に向けた自然な言い方 |
| --- | --- |
| シーズン1〜2と合わせて、同じ日に続けて観られる並びです。 | シーズン1〜2と合わせて視聴してみましょう！ |
| 3期分が同じ日にそろうので、1期から順に追うにも続きから観るにも起点になります。 | 1期から順に、3期分をまとめて楽しめます。 |
| 日をおいて1本ずつ増えていく並びになっています。 | 気になる作品の配信開始日を控えておきましょう。 |
| 月末に向けて話題作が続く並びです。 | 月末にかけて話題作が続きます。 |

**使わない言い回し**（品質ゲートが見ている）

    〜という並びです／並びになっています
    〜する形です／形になっています
    〜の起点になります
    〜という構成です

> ★ 「9月1日に11作がまとめて配信開始予定です」は**事実**なので書いてよい。
>   禁じているのは、事実のあとに付ける**「並びです」「形です」という記事側の説明**。

## 2. 配信の裏側を推測しない

**ライセンス・権利・契約の事情は、素材のどこにも無い。**
同じ制作会社の作品が同じ日に並ぶ理由を、こちらで推し量って書かない。

| ✕ | ○ |
| --- | --- |
| まとめてライセンスされたものが同時に配信開始となったと考えられます。 | （書かない。かわりに作品そのものを1〜2文で説明する） |
| 契約が切れたため一斉に終了するとみられます。 | 5作とも9月1日に見放題配信が終了します。 |

**「同じ制作会社の作品です」までは事実なので書いてよい**（素材に制作会社がある場合）。
そこから先の**なぜ**に踏み込まない。

> ★ 外れても読者には確かめようがなく、当たっていても観るかどうかの判断は変わらない。
>   **書く理由が無い一方で、外したときの損は記事全体の信用に及ぶ。**

その分の行数は、作品の説明に使う。あらすじ・監督・出演者・制作会社は素材にある。

## 3. 作品の魅力は「事実」で書く

**あらすじの言い換えで終わらせない。** 読者が知りたいのは
「どんな話か」だけでなく「**なぜその作品が好かれているのか**」。

素材に `リサーチ` の行がある作品は、そこにある事実を根拠に**1文足す。**
作風・評判・広がり方は感想ではなく事実なので、調べたうえで書けば推測にならない。

| ✕ あらすじだけ | ○ 魅力まで届く |
| --- | --- |
| 高校生のなでしこが富士山を見に自転車で本栖湖へ向かう話です。 | ソロと大人数のキャンプを対等に描くのが持ち味で、実在のキャンプ場を作者が下見して描いた風景と、道具や野外調理の手つきがそのまま画面に出ます。 |
| 白熊がカフェを始める日常アニメです。 | 動物たちの脱力した掛け合いと言葉遊びが続く1本で、原作は◯◯万部を超えています。 |

**使える事実の例**

- 作風・語り口（何をどう描く作品か）
- 累計発行部数・興行収入・受賞歴など、**数字と固有名詞で言えるもの**
- シリーズの広がり（何期まで作られたか、劇場版があるか、実写化されたか）
- 舞台になった土地（聖地巡礼で知られる、など）

**やってはいけないこと**

- **リサーチの文章をそのまま写す。** 出典は CC BY-SA で、写せば同じ条件での
  再配布義務が生じる。**事実だけを読み取って、こちらの言葉で書く**
- リサーチが**別作品**（小説版・ドラマ版・同名の別作品）のときに使う。
  素材の `出典:` を見て、対象作品の項目かどうかを必ず確かめる
- リサーチが無い作品を、他の作品の情報や自分の記憶で埋める。
  **無い作品は素材の範囲で書く**（1〜2文で終わってよい）
- 数字を丸めたり盛ったりする。**書けるのは素材にある数字だけ**

> 下調べは `npm run research` が日本語版 Wikipedia の「概要」「作風」「評価」節から集める。
> 取れなかった作品には `リサーチ` の行が無い。

## 4. 事実と、事実でないものを混ぜない

- 素材に無い日付・数字・人名を書かない（各テンプレートの「絶対に守ること」）
- 「〜と考えられます」「〜とみられます」で**推測を事実らしく見せない。**
  推測が必要な場面なら、そもそも書かない

## 5. 節の中で最初に触れる2作は、表の題名を省略せずに書く

**節に挿す作品ポスターは、地の文が表の題名と同じ文字列で触れた作品から選ばれる**
（`site/scripts/make-sections.mjs` の `pickHighlights`）。

シリーズ物は2作目以降を略称で書きたくなる。

    表  ハリー・ポッターと賢者の石 ／ ハリー・ポッターと秘密の部屋 ／ ハリー・ポッターとアズカバンの囚人
    地  「賢者の石」は……「秘密の部屋」は2年生、「アズカバンの囚人」は3年生

これだと**完全一致するのが1つだけ**になり、10行の表に絵が1枚しか付かない
（2026-09-01 の添削）。

- **その節で最初に取り上げる2作は、表と1文字も違わない題名で書く**
- 3作目からは略称でよい。読みやすさのほうが大事

> ★ 足りないぶんは評価の高い順で自動的に埋まるので、**破綻はしない。**
>   ただし埋まった絵は、読者がすぐ上で読んだ文章と関係のない作品になる。
>   「絵と文章が噛み合っている」状態は、書き手にしか作れない。

## 6. 出演者の出しかた（2026-09-08 追加・同日に改訂）

**読者は演者の羅列を読まない。** 素材には作品ごとに5人の名前が入っているので、
そのまま書くと「出演は蒼井優、佐藤健、江口洋介、伊勢谷友介、武井咲。」という文が
節の数だけ並ぶ。**どの名前も読み飛ばされ、段落の密度だけが下がる**（2026-09-08 の添削）。

かといって箇条書きを表の下にそのまま置くと、今度はそれが**主張しすぎる**。

> 出演者の箇条書きですが、主張しすぎです。
> 「出演者」フィールドは文章として読ませる必要はなくて、
> 出来る限り文章量を少なく、領域も小さくて良いです。

そこで出しどころを2つに分けた。**どちらも「短く」が要件**。

| 置き場所 | 出すもの | 量 | どの記事 |
| --- | --- | --- | --- |
| **表の「出演者」列** | **主演と助演を1名ずつ**（計2名まで） | 1セル | **全記事タイプ** |
| **表の直後の箇条書き** | **主演だけ** | 1〜2行 | **`series` / `special`** |
| 地の文 | **名前を出す理由が同じ文の中にあるときだけ** | — | 全記事タイプ |

### 表の「出演者」列は主演＋助演の2名まで

**網羅しない。** 素材の `出演` の行から、主演と助演を1名ずつ選ぶ。

| | 書き方 |
| --- | --- |
| 実写 | `佐藤健、蒼井優` のように**2名まで** |
| **アニメ** | **`キャラ名（CV.声優）`** の形にする |
| 素材に `出演` の行が無い | **`—`**。推測で埋めない |

- **素材の `出演` は並び順が主演順ではない。** どちらが主演か分からない作品では、
  代表として2名を挙げるだけにして**「主演」と書かない**
- この列は**「評価」の列と入れ替えたもの**。評価は記事に出さず、
  素材の値は**表の行を並べる順番の目安**としてだけ使う（各テンプレートの列の項）

★ **アニメの「キャラ名（CV.声優）」は、素材にキャラ名があるときだけ。**
  いまの素材（`data/cast.json`）は**声優の名前しか持っていない**ので、
  多くのアニメは `—` になる。**キャラ名を推測で補ってはいけない。**

### 表の直後の箇条書きは主演だけ

    **出演者**

    - 佐藤健（実写5作すべてに主演）

- **サイトが小さな枠にたたむ**（`site/plugins/rehype-cast.ts`）。
  **文章として読ませるものではない**ので、名前と括弧書きだけにする
- **置くのは主題が1つの記事（`series` / `special`）だけ。** 月次記事は作品がばらばらで、
  主演をまとめて名乗れない（表の列だけで足りる）
- アニメは**キャラ名（CV.声優）**の形にする
- **主演と書けるのは、リサーチに「主演・◯◯」のような記述がある作品だけ。**
  確かめられない記事では**箇条書きごと置かない**
- 共演者を並べない。それは表の「出演者」の列が1行ずつ受け持っている
- **同じ主演を節ごとに繰り返さない。** サービスが分かれていても主演は同じなので、
  **記事の最初の表の下に1回だけ**置く（2026-09-08）。
  同じ1行が3回出ると、それだけで「読ませようとしている」ことになる

### 地の文で名前を出してよいのは、名前が説明に効くときだけ

**「その名前を出す理由」が同じ文の中にあること。** 例えば次のような場合。

| ○ 書いてよい | なぜ |
| --- | --- |
| 監督が交代したあとも、同じ役でサム・ニールが戻りました | 作品の転機を説明している |
| 製作にはトム・クルーズが関わっており、1作目から続いています | 作り手としての立場の話 |
| 主演の佐藤健はベストアクション男優の最優秀賞を受けました | 受賞という事実の主語 |

    ✕ 出演は蒼井優、佐藤健、江口洋介、伊勢谷友介、武井咲。
      （名前を出す理由が文の中に無い。これは表と、表の下の箇条書きの仕事）

★ **特殊な状況では地の文に書いてよい。** 対象が1作しかない記事や、
  演者そのものが記事の主題になっている回まで縛る決まりではない。
