# 文章の決まり（全記事タイプ共通）

**構成は記事タイプごとのテンプレートにある。** ここにあるのは、
どの記事でも同じように守る書き方の決まり。

> ★ タイトルの決まりが `naming.md` に1枚だけあるのと同じ理由で、ここも1枚にしてある。
>   4つのテンプレートに書き写すと、必ずどれかが古くなる。

---

## この決まりが向いている先（2026-09-10 追加）

**記事が果たす役割は2つだけ。** 以下の節はすべてこの2つに向いている。

1. **冒頭で離脱させず、少なくとも表と検索リンクまでスクロールしてもらう**
   → **導入は簡潔に。** 表への誘導は「表がそこにある」以上のことをしない
   （どの記事にも同じ形で入る案内文は、読者にとって情報量ゼロ）
2. **作品ごとの解説は、ファンが読んでも納得する中身を簡潔に**
   → **深く調べて、短く書く。** 長く書くことではない

> これらの視点が再来訪の増加に繋がると信じています。
>
> — 2026-09-10・運用者

**迷ったときは「この1文は、読者を次の行へ進ませるか」で決める。**
進ませないなら、事実として正しくても落とす。

---

## 1. 記事の作りを読者に説明しない

**読者は「何が観られるか」を知りたい。記事がどう組み立てられているかは要らない。**

節のまとめ方（同じ日・同じシリーズ・同じ制作会社）は**書き手の都合**であって、
読者に伝える情報ではない。まとめ方をそのまま文章にすると、
作品の話が消えて「並び方の解説」になってしまう。

結びは、**読者が次にできること**で終える。

| ✕ 記事の作りの説明 | ○ 読者に向けた自然な言い方 |
| --- | --- |
| シーズン1〜2と合わせて、同じ日に続けて観られる並びです。 | シーズン1〜2と合わせて視聴してみましょう！ |
| 3期分が同じ日にそろうので、1期から順に追うにも続きから観るにも起点になります。 | 1期から順に、3期分をまとめて楽しめます。 |
| 日をおいて1本ずつ増えていく並びになっています。 | 気になる作品の配信開始日を控えておきましょう。 |
| 月末に向けて話題作が続く並びです。 | 月末にかけて話題作が続きます。 |

**使わない言い回し**（品質ゲートが見ている）

    〜という並びです／並びになっています
    〜する形です／形になっています
    〜の起点になります
    〜という構成です
    公開順／終了日順に並べています
    まとまって外れました
    〜が山です

> ★ 「9月1日に11作がまとめて配信開始予定です」は**事実**なので書いてよい。
>   禁じているのは、事実のあとに付ける**「並びです」「形です」という記事側の説明**。

### ★ 並べ方と、素材の偏りに触れない（2026-09-10 追加）

**表の並び順を宣言しない。** 公開順・終了日順に並んでいることは、
**サイトの構造として自然とそうなっているべきもの**で、
宣言が要る時点で読者は並びを読み解かされている。

> 公開順に並べている、という当たり前の事を宣言する必要ありません。
> 「サイトの構造として自然とそうなっているべき＝違反で読者が離れる」
>
> — 2026-09-10 の添削（Disney+ 終了済み・名探偵コナン48本）

**素材の偏りも読者に見せない。** 何本が同じ日に集まったか、どの日に多いかは
**こちらの観測**であって、作品の話ではない。

| ✕ データの構造の話 | ○ 作品の話 |
| --- | --- |
| 公開順に並べています。 | （書かない。表がその順に並んでいる） |
| 同じ制作会社の作品が7本まとまって外れました。 | 「評決のとき」「マイ・ボディガード」など7本が9月2日に見放題配信を終了しました。 |
| 9月4日がこの月の山です。 | （書かない。日付は表の「終了日」の列が持っている） |
| 終了は2つの日に大きく偏りました。 | 9月2日に◯本、9月4日に◯本が終了しました。 |

★ **「9月2日に7本が終了しました」は事実なので書いてよい。**
  禁じているのは、その事実を**データの塊として語り直す**言い方
  （「まとまって外れました」「山です」「偏りました」）。

★ **リードの固定文言はこの決まりの外。** `arrivals-lead-closer` の
  「配信開始日順に解説していきますので」は、**読者を本文へ送り出す1文**であって
  表の並びの説明ではない。固定文言は一字一句そのまま使う（言い換えない）。

## 2. 配信の裏側を推測しない

**ライセンス・権利・契約の事情は、素材のどこにも無い。**
同じ制作会社の作品が同じ日に並ぶ理由を、こちらで推し量って書かない。

| ✕ | ○ |
| --- | --- |
| まとめてライセンスされたものが同時に配信開始となったと考えられます。 | （書かない。かわりに作品そのものを1〜2文で説明する） |
| 契約が切れたため一斉に終了するとみられます。 | 5作とも9月1日に見放題配信が終了します。 |

**「同じ制作会社の作品です」までは事実なので書いてよい**（素材に制作会社がある場合）。
そこから先の**なぜ**に踏み込まない。

> ★ 外れても読者には確かめようがなく、当たっていても観るかどうかの判断は変わらない。
>   **書く理由が無い一方で、外したときの損は記事全体の信用に及ぶ。**

その分の行数は、作品の説明に使う。あらすじ・監督・出演者・制作会社は素材にある。

## 3. 作品の魅力は「事実」で書く

**あらすじの言い換えで終わらせない。** 読者が知りたいのは
「どんな話か」だけでなく「**なぜその作品が好かれているのか**」。

素材に `リサーチ` の行がある作品は、そこにある事実を根拠に**1文足す。**
作風・評判・広がり方は感想ではなく事実なので、調べたうえで書けば推測にならない。

| ✕ あらすじだけ | ○ 魅力まで届く |
| --- | --- |
| 高校生のなでしこが富士山を見に自転車で本栖湖へ向かう話です。 | ソロと大人数のキャンプを対等に描くのが持ち味で、実在のキャンプ場を作者が下見して描いた風景と、道具や野外調理の手つきがそのまま画面に出ます。 |
| 白熊がカフェを始める日常アニメです。 | 動物たちの脱力した掛け合いと言葉遊びが続く1本で、原作は◯◯万部を超えています。 |

**使える事実の例**

- 作風・語り口（何をどう描く作品か）
- 累計発行部数・興行収入・受賞歴など、**数字と固有名詞で言えるもの**
- シリーズの広がり（何期まで作られたか、劇場版があるか、実写化されたか）
- 舞台になった土地（聖地巡礼で知られる、など）
- **作り手・関係者の言葉**（誰が・何と言ったか。リサーチにあるものだけ）

★ **作り手の言葉は、数字より効くことがある**（2026-09-10 の添削で評価された書き方）。

      後年の劇場版で脚本を担当した大倉崇裕は、シリーズの中でこの作品が最も好きだと語っています。

  「人気があります」と書くかわりに、**誰がそう言ったか**を出すと、
  同じ1文で作品の位置づけまで伝わる。**言った人と、言った中身の両方が
  リサーチにあるときだけ**使う（発言者を推測しない）。

**やってはいけないこと**

- **リサーチの文章をそのまま写す。** 出典は CC BY-SA で、写せば同じ条件での
  再配布義務が生じる。**事実だけを読み取って、こちらの言葉で書く**
- リサーチが**別作品**（小説版・ドラマ版・同名の別作品）のときに使う。
  素材の `出典:` を見て、対象作品の項目かどうかを必ず確かめる
- リサーチが無い作品を、他の作品の情報や自分の記憶で埋める。
  **無い作品は素材の範囲で書く**（1〜2文で終わってよい）
- 数字を丸めたり盛ったりする。**書けるのは素材にある数字だけ**

> 下調べは `npm run research` が日本語版 Wikipedia の「概要」「作風」「評価」節から集める。
> 取れなかった作品には `リサーチ` の行が無い。

## 4. 事実と、事実でないものを混ぜない

- 素材に無い日付・数字・人名を書かない（各テンプレートの「絶対に守ること」）
- 「〜と考えられます」「〜とみられます」で**推測を事実らしく見せない。**
  推測が必要な場面なら、そもそも書かない

## 5. 節の中で最初に触れる2作は、表の題名を省略せずに書く

**節に挿す作品ポスターは、地の文が表の題名と同じ文字列で触れた作品から選ばれる**
（`site/scripts/make-sections.mjs` の `pickHighlights`）。

シリーズ物は2作目以降を略称で書きたくなる。

    表  ハリー・ポッターと賢者の石 ／ ハリー・ポッターと秘密の部屋 ／ ハリー・ポッターとアズカバンの囚人
    地  「賢者の石」は……「秘密の部屋」は2年生、「アズカバンの囚人」は3年生

これだと**完全一致するのが1つだけ**になり、10行の表に絵が1枚しか付かない
（2026-09-01 の添削）。

- **その節で最初に取り上げる2作は、表と1文字も違わない題名で書く**
- 3作目からは略称でよい。読みやすさのほうが大事

> ★ 足りないぶんは評価の高い順で自動的に埋まるので、**破綻はしない。**
>   ただし埋まった絵は、読者がすぐ上で読んだ文章と関係のない作品になる。
>   「絵と文章が噛み合っている」状態は、書き手にしか作れない。

## 6. 出演者の出しかた（2026-09-08 追加・同日に改訂）

**読者は演者の羅列を読まない。** 素材には作品ごとに5人の名前が入っているので、
そのまま書くと「出演は蒼井優、佐藤健、江口洋介、伊勢谷友介、武井咲。」という文が
節の数だけ並ぶ。**どの名前も読み飛ばされ、段落の密度だけが下がる**（2026-09-08 の添削）。

かといって箇条書きを表の下にそのまま置くと、今度はそれが**主張しすぎる**。

> 出演者の箇条書きですが、主張しすぎです。
> 「出演者」フィールドは文章として読ませる必要はなくて、
> 出来る限り文章量を少なく、領域も小さくて良いです。

そこで出しどころを2つに分けた。**どちらも「短く」が要件**。

| 置き場所 | 出すもの | 量 | どの記事 |
| --- | --- | --- | --- |
| **表の「出演者」列** | **主演と助演を1名ずつ**（計2名まで） | 1セル | **全記事タイプ** |
| **表の直後の箇条書き** | **主演だけ** | 1〜2行 | **`series` / `special`** |
| 地の文 | **名前を出す理由が同じ文の中にあるときだけ** | — | 全記事タイプ |

### 表の「出演者」列は主演＋助演の2名まで

**網羅しない。** 素材の `出演` の行から、主演と助演を1名ずつ選ぶ。

| | 書き方 |
| --- | --- |
| 実写 | `佐藤健、蒼井優` のように**2名まで** |
| **アニメ** | **`キャラ名（CV.声優）`** の形にする |
| 素材に `出演` の行が無い | **`—`**。推測で埋めない |

- **素材の `出演` は並び順が主演順ではない。** どちらが主演か分からない作品では、
  代表として2名を挙げるだけにして**「主演」と書かない**
- この列は**「評価」の列と入れ替えたもの**。評価は記事に出さず、
  素材の値は**表の行を並べる順番の目安**としてだけ使う（各テンプレートの列の項）

★ **アニメの「キャラ名（CV.声優）」は、素材にキャラ名があるときだけ。**
  いまの素材（`data/cast.json`）は**声優の名前しか持っていない**ので、
  多くのアニメは `—` になる。**キャラ名を推測で補ってはいけない。**

### 表の直後の箇条書きは主演だけ

    **出演者**

    - 佐藤健（実写5作すべてに主演）

- **サイトが小さな枠にたたむ**（`site/plugins/rehype-cast.ts`）。
  **文章として読ませるものではない**ので、名前と括弧書きだけにする
- **置くのは主題が1つの記事（`series` / `special`）だけ。** 月次記事は作品がばらばらで、
  主演をまとめて名乗れない（表の列だけで足りる）
- アニメは**キャラ名（CV.声優）**の形にする
- **主演と書けるのは、リサーチに「主演・◯◯」のような記述がある作品だけ。**
  確かめられない記事では**箇条書きごと置かない**
- 共演者を並べない。それは表の「出演者」の列が1行ずつ受け持っている
- **同じ主演を節ごとに繰り返さない。** サービスが分かれていても主演は同じなので、
  **記事の最初の表の下に1回だけ**置く（2026-09-08）。
  同じ1行が3回出ると、それだけで「読ませようとしている」ことになる

### 地の文で名前を出してよいのは、名前が説明に効くときだけ

**「その名前を出す理由」が同じ文の中にあること。** 例えば次のような場合。

| ○ 書いてよい | なぜ |
| --- | --- |
| 監督が交代したあとも、同じ役でサム・ニールが戻りました | 作品の転機を説明している |
| 製作にはトム・クルーズが関わっており、1作目から続いています | 作り手としての立場の話 |
| 主演の佐藤健はベストアクション男優の最優秀賞を受けました | 受賞という事実の主語 |

    ✕ 出演は蒼井優、佐藤健、江口洋介、伊勢谷友介、武井咲。
      （名前を出す理由が文の中に無い。これは表と、表の下の箇条書きの仕事）

★ **特殊な状況では地の文に書いてよい。** 対象が1作しかない記事や、
  演者そのものが記事の主題になっている回まで縛る決まりではない。

## 7. 数字と作品名だけで段落を作らない（2026-09-10 追加）

**上映時間と興行収入を、作品ごとに書き並べない。**
読者はその数字で観るかどうかを決めていない。

> 上映時間・興行収入を作品ごとに解説する必要なし
> （読者にとって不要な情報。文脈に必要ならばアクセントとして）
>
> — 2026-09-10 の添削（Disney+ 終了済み・名探偵コナン22作）

| ✕ 数字を並べただけ | ○ 数字が何かを説明している |
| --- | --- |
| 第1作は上映時間95分、興行収入11億円。第6作は興行収入34億円、上映時間107分。 | 第1作は、犯人による殺人を描かずに爆弾魔との対決だけで話を通した1本です。 |
| 第21作は68億9,000万円、第19作は44億8,000万円、第18作は41億1,000万円です。 | 第20作は前作から20億円近く増えて63億3,000万円になりました。 |

- **上映時間は書かない。** 素材にあっても、記事に出す場面はほとんど無い
- **興行収入は記事に1〜2回まで。** 出すのは**転機**（跳ね上がった作品、到達点）を
  説明するときだけで、順位表を文章にし直さない
- 受賞歴も同じ。**いちばん重いもの1つ**でよい（3節「1文足す」）

### 作品名を並べただけの文を書かない

**作品名に触れるなら、読者がまだ知らないことを1つ添える。**
題名と数字だけを連ねた段落は、読み終えても読者に何も残らない。

> 作品名を読むだけで読者は疲れます。作品のあらすじに触れない今回の文章では、
> タイトルと数字の羅列となり「読んで新しく得る情報、シリーズ全体の魅力が伝わりにくい」
>
> — 2026-09-10 の添削（同上）

    ✕ 「大丈夫、愛だ」「ピノキオ」「三十ですが十七です」の3作が9月3日にそろって外れています。

    ○ 韓国ドラマ3作は9月3日に終了しました。（作品名は表が持っている）

    ○ 韓国ドラマ3作のうち「ピノキオ」は、嘘をつくとしゃっくりが出る体質の主人公が
      報道の現場に入る1本です。（1作だけ選んで、知らないことを1つ書く）

★ **添えるものが無いなら、その作品は表に任せる。**
  無理に文章を作るより、**触れないほうが記事は良くなる。**

### 「そのほか」の節は、表と0〜2文でよい

厚い節を2つ書いたあとの「そのほかに終了した◯本」は、**埋めなくてよい。**
全作品は表に載っているので、解説が無くても記事は成立している。

> 「その他」でまとめる場合は、特筆すべき作品のみ作品名を挙げ解説して良い。
> それを行わない場合、このような作品名のみ挙げて内容が無い文章になります。
> 無理に文章を作るのではなく、必要ない（他にメインシリーズを解説したケースなど）は
> 解説不要で表のみ。それを簡潔に述べる。
>
> — 2026-09-10 の添削（Disney+ 終了済み）

**書き方は2つだけ。どちらかを選ぶ。**

| | 書くもの |
| --- | --- |
| **特筆すべき1〜2作がある** | その作品だけを1〜2文で。**残りは表に任せる** |
| **無い** | **表だけ置いて、1文で締める。**（例:「そのほかの◯本は上の表のとおりです。」） |

    ✕ 日本の作品では「A」「B」「C」が9月2日に終了しました。韓国ドラマは
      「D」「E」「F」の3作が9月3日にそろって外れています。ドキュメンタリーと
      報道番組も7本並びました。「G」「H」「I」…
      （題名を読ませているだけで、読者が新しく得るものが無い）

    ○ そのほかの19本は、日本のドラマ・韓国ドラマ・ドキュメンタリーが中心です。
      上の表で終了日を確認できます。

★ 節の分量そのもの（厚い節は2つまで）は各記事タイプのテンプレートにある
  （`ended.md` / `leaving.md` / `special.md`）。ここにあるのは**文章の書き方**だけ。

## 8. あらすじは1作ずつ、具体で書く（2026-09-10 追加）

### 2作を「前者・後者」で畳まない

**代名詞で受けると、読者は前の文へ戻って数え直すことになる。**

    ✕ 同じ年に続けて公開された対の作品で、前者は1879年を舞台にシリーズで最も
      手強い敵とその一党が仕掛ける復讐を、後者は時間をさかのぼって、
      人斬りと恐れられていた時代から不殺を誓うまでを描きます。

    ○ 『るろうに剣心　最終章 The Final』は1879年の東京が舞台で、主人公が
      これまでで最も手強い敵の復讐に向き合います。『るろうに剣心　最終章
      The Beginning』はそこから時代をさかのぼり、主人公が人斬りをやめるまでを
      描いた前日譚です。（題名は表と1文字も違わない形で。5節）

**題名で始めて、1作につき1文。** 2作なら2文でよい。
「前者」「後者」「こちらは」「もう1本は」で対にして畳まない。

> あらすじを読んでも意味が通じない典型です。前者は・後者はで区切っていますが、、
>
> — 2026-09-10 の添削（「るろうに剣心」シリーズ）

### 抽象的な要約より、具体を1つ

**修飾を重ねた1文より、具体的な事実が1つあるほうが速く伝わる。**

    ✕ 幕末に人斬りとして恐れられた剣客が、明治に入って刃を裏返した刀を手に、

## 9. 同じ名前・同じ褒め言葉を繰り返さない（2026-09-10 追加）

> 文中に「谷垣健治」氏が二度出てきます。ベストアクションという単語も何度も。

>

- **人名は記事に1回。** 2回目は役割で受ける（「アクション監督」「同じ監督が」）
- **同じ賞・同じ評価語を並べない。** 賞は**いちばん重いもの1つ**（7節）
- 2回目を書きたくなったら、**1回目の文が足りていない**ことが多い。
  2か所に散らすのではなく、1か所で言い切る

## 10. 読者が知らない名前を見出しに立てるなら、その名前を記事が引き受ける（2026-09-10 追加）

節を**制作会社・レーベル・放送枠**で束ねるときの決まり。
読者はふつうその名前を知らない。**知らない名前を見出しに置くなら、
「それが何なのか」を記事が1つ引き受ける。**

> リージェンシーエンタープライズをわざわざ取り上げて書くならば、この会社の作品の
> 魅力は何？＝観る上での楽しみ方・特徴などリサーチし書き起こしてほしい
>
> — 2026-09-10 の添削（Disney+ 終了済み）

**書けること**（素材の `制作` の行とリサーチから読み取れる範囲）

- どんな作品を作ってきたところか、どこと組んで作っているか
- その束に共通するもの（年代・ジャンル・作りの特徴）

**書けないなら、見出しをその名前にしない。**
ジャンル・国・年代など**読者が知っている束**に替えるか、「そのほか」に送る。
会社名を見出しに置いて、中身が作品名の羅列になるのがいちばん悪い形（7節）。

★ **束ねた理由（なぜ同じ日に終わるのか）は書かない。** それは2節の推測にあたる。
  書くのは**その束が何なのか**であって、**なぜそうなったか**ではない。
