# ショート動画の台本テンプレート

このファイルを編集すれば、**全ての台本の型が変わる。** コードは触らなくてよい。

| 変えたいもの | 場所 |
| --- | --- |
| 構成・尺・禁止事項 | このファイル |
| 締めの固定文言・概要欄の型 | `fixed-phrases.md`（`short-` で始まるキー） |
| 出来上がった台本 | リポジトリ直下の `shorts/`（手で直してよい） |

## この台本が果たす役割

**記事の代わりではない。記事へ連れて行くための30秒。**

30秒で読み上げられるのは約180字しかない。記事が扱う数十本のうち、
台本に載るのは**4〜5本だけ**。全部を見せようとすると、どれも印象に残らないまま終わる。

だから台本の仕事は1つだけ。

> **その月にあった「1つのまとまり」を見せて、残りを概要欄に送る。**

まとまりは記事を書くときに既に見つけている（同じ日に終わる同一シリーズ、
同じ制作会社の一斉配信など）。**それがそのままショートのフックになる。**
記事の軸と台本の軸は同じものであること。別の切り口を新たに探さない。

## 尺（守れないと動画が成立しない）

| | |
| --- | --- |
| 全体 | **30秒以内。** 超えたら作品を減らす。早口にして詰め込まない |
| 読み上げの合計 | **150〜170字**（約6字/秒 ＋ カットの間） |
| カット数 | **5〜7**（1カットあたり3〜6秒） |
| 1カットの読み上げ | **35字以内** |

字数は `npm run shorts` が数え直して秒数を出す。書いたあとに必ず確認する。

## 構成

**カット1がフック、最後のカットが締め。間が本編。** この3つの役割は変えない。

### カット1（フック・0〜5秒）

**まとまりの正体を、最初の一言で言い切る。**
ここで見られなければ残り25秒は存在しないのと同じ。

- サービス名と「何が起きたか」を1文に入れる
- 作品名を1つだけ出してよい（いちばん知られているもの）
- 「今回は」「今月の」のような前置きを置かない。**いきなり中身から入る**

```
○  Netflixに、京都アニメーション作品がまとめて見放題で入りました。
×  今月の配信開始情報をまとめてご紹介します。
```

### カット2〜（本編）

**1カット＝1作品**、または**1カット＝同じ日のまとまり**。

- 作品名・日付・サービスを、読み上げと画面の両方で示す
- あらすじは書かない。**30秒では入らないし、記事で読めばよい**
- 記事に書いた解説を要約しようとしない。台本は「見出しの読み上げ」に近い

### 最後のカット（締め）

**残りの本数を言ってから、固定文言で終える。**

```
今月見放題に入ったアニメは34本。詳細は概要欄にて。
                              ~~~~~~~~~~~~~~~~
                              一字一句この通り
```

締めの固定文言は `fixed-phrases.md` の `short-closer`。
**言い換えない。** 毎回同じ終わり方にすることで、視聴者が概要欄を見る動作を覚える。

## 画面に出す文字（テロップ・補足）

カットごとに2つ書く。**この文字がそのまま画像として生成される**ので、
思いつきの飾り文句ではなく、画面に置いて成立する短さにすること。

| 欄 | 中身 | 長さ |
| --- | --- | --- |
| **テロップ** | そのカットの主役。作品名か、まとまりの正体 | **20字以内** |
| **補足** | 日付とサービス名 | **16字以内** |

- **ナレーションをそのまま書き写さない。** 同じ文が耳と目に二重に来る
- テロップは体言止めでよい。画面の文字に「です・ます」は要らない
- 補足は `8月3日 Netflix` の形で揃える。日付が無いカットは空欄にする

## 禁止事項

**記事と同じ規則が全部かかる。そのうえで、音声固有の禁止が2つある。**

### 1. 邦題が確定していない作品を出さない（音声固有）

記事なら原題をそのまま書けば済む。**音声では英語の原題を読み上げても視聴者に伝わらず、
読み方を推測した時点で誤情報になる。**
素材に「★邦題が未確認」と付いている作品は、**台本の候補に入れない。**

### 2. 評価スコアを画面にも音声にも出さない（記事と同じ）

30秒では出典を示せない。数字だけが独り歩きする。

### 3. データに無いことを足さない（記事と同じ）

- 与えられた日付**以外の日付を書かない**
- 与えられていない作品を追加しない
- あらすじ・受賞歴・シリーズの順番を補わない
- 記号は全角に統一する（作品名に含まれる半角記号はそのまま）

## 概要欄は書かなくてよい

記事URL・出典表記・注意書きは**パイプラインが機械的に組み立てる。**
出典表記は動画にも義務があり、書き忘れが規約違反に直結するので、
人が毎回書く形にしない。台本に書くのはカット表だけでよい。
