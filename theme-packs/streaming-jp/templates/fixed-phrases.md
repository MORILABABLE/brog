# 固定文言

**毎月そのまま使う文言**をここに集める。記事ごとに言い換えない。

ここに書いた内容は、記事を書くときの指示にも、書いたあとの品質チェックにも
そのまま使われる。文言を変えたいときはこのファイルだけを直せばよい。

キーの接頭辞が、その文言を使う記事タイプを表す。

| 接頭辞 | 使う記事 | テンプレート |
| --- | --- | --- |
| `leaving-` | 見放題終了**予定** | `leaving.md` |
| `ended-` | 見放題終了**済み** | `ended.md` |
| `arrivals-` | 見放題配信開始（ジャンル別） | `arrivals.md` |
| `arrivals-service-` | 見放題配信開始（**サービス別・月内更新**） | `arrivals-service.md` |
| `special-` | **特報**（主題を指定して書く） | `special.md` |
| `short-` | **ショート動画の台本**（記事と同時に作る） | `short-script.md` |
| なし | 全記事共通 | — |

`leaving-` と `ended-` は読者に渡すものが正反対なので、文言を流用しないこと。
終了予定は「観ておきましょう」、終了済みは「他で探せます」で締める。

`{...}` は生成時に実際の値へ置き換わる。手で数字を埋めた形で書かないこと。

| 差し込み | 中身 | 例 |
| --- | --- | --- |
| `{月}` | 記事が対象とする月 | `8` |
| `{サービス}` | その記事が扱うサービス名。**サービス軸の記事では1社、ジャンル軸の記事では複数** | `Netflix` / `NetflixとAmazon Prime Video` |
| `{基準日}` | 記事を書いた日 | `8月9日` |
| `{本数}` | 記事で扱う作品数 | `32` |
| `{ジャンル}` | 配信開始記事のジャンル | `洋画・海外ドラマ` |
| `{主題}` | **特報だけ**。その記事が扱う主題（`--topic` の値） | `「007」シリーズ` |
| `{追加本数}` | **更新版だけ**。前回の版のあとに新しく載る作品数 | `5` |
| `{記事タイトル}` | **台本の概要欄だけ**。書き上がった記事のタイトル | — |
| `{記事URL}` | **台本の概要欄だけ**。記事の公開URL | — |
| `{出典}` | **台本の概要欄だけ**。素材の出どころから機械的に決まる帰属表示 | — |
| `{ハッシュタグ}` | **台本の概要欄だけ**。記事のタグから機械的に作る | `#Netflix #配信終了` |

<!-- 記号は全角に統一する。！（感嘆符）と（）（括弧）を半角で書かない。 -->

## leaving-lead-first-sentence

【{月}月終了】{サービス}で見放題配信が終了する作品を、終了日順にまとめました！記事作成時点（{基準日}時点）では{本数}本が見放題終了対象です。

<!--
リードの1文目。記事の要点そのもので、読者が最初に見る一文。
毎月この型を流用し、月・サービス名・基準日・本数だけを差し替える。

「記事作成時点（○月○日時点）」を必ず入れる理由:
月の途中で読まれたとき、本数が合わないのは記事が古いからだと分かるようにするため。
-->

## attribution-unext

> 配信状況・見放題終了日は U-NEXT の作品ページに掲載されている情報にもとづきます（{基準日}時点）。終了日は変更される場合があります。

<!--

U-NEXT 側に帰属表示の義務はないが、**出どころと基準日は読者のために書く**。
終了日は動くので（延長も前倒しもある）、断定しないことをここで明示しておく。
実際に日付が動いたときは `npm run unext:refresh` が検出するので、
記事側の訂正はそこを見て判断する。
-->

## short-closer

<!--
