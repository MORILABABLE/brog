# 追従枠のサムネイル置き場

本文右の追従枠（`src/components/FollowRail.astro`）に出す、常設ページごとの小さな画像。

## ファイル名がそのまま対応先になる

拡張子は `.png` / `.jpg` / `.jpeg` / `.webp` のいずれか。

| ファイル名 | 出る場所 |
|---|---|
| `netflix.png` | Netflix の終了予定ページ・新着ページ |
| `prime-video.png` | Amazon Prime Video の終了予定ページ・新着ページ |
| `disney-plus.png` | Disney+ の新着ページ |
| `stats.png` | 見放題の増減ページ |

**キーは `src/lib/events-data.ts` のサービスキーと同じ。** サービスを増やしたら
同じキーのファイルを置けば自動で拾われる（コード変更は不要）。

## 仕様

- **表示サイズ 36×36px の正方形。** `object-fit: cover` で切り抜くので、
  元画像は正方形か、中央に主題がある画像にする
- **元画像は 72×72px 以上**を推奨（高解像度ディスプレイ用）。大きすぎても
  ビルド時に縮小・WebP変換されるので害はない
- 角丸6pxはCSS側で付ける。画像に丸みを焼き込まない

## 画像が無くてもよい

置いていないキーは**文字だけの行**になる。レイアウトは崩れない。
1つずつ用意していけばよく、全部揃うまで待つ必要はない。

## ライセンスに注意

**各サービスの公式ロゴをそのまま使うと商標の問題になりうる。**
当サイトは広告収入を得ているため、ロゴの使用は各社のブランドガイドラインの
範囲を超える可能性がある。自作のアイコン、または利用条件を確認した素材を使うこと。
判断に迷うなら**文字だけ**にしておくのが安全（それで壊れない設計にしてある）。
